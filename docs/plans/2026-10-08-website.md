**Goal:** Replace the 29-line "OpenVIBES packages" page with a dark, light/dark-aware landing page for newcomers (live demo + get started, four features, principles, stage and roadmap, three install steps) and move the package/key details to `packages.html`.

**Architecture:** Hand-written static files in the site repository: `index.html`, `packages.html`, `site.css`, `assets/` (wordmarks, WebP screenshots). No build step, no JavaScript. `scripts/build-repo.sh` copies them into the Pages site beside `install.sh` and the package repository. A small shell checker (`tests/check-site.sh`) proves every local link and asset exists and the images stay under 1 MB.

**Tech Stack:** HTML, CSS (custom properties, `prefers-color-scheme`), bash (tests, ShellCheck), ImageMagick `magick` (PNG → WebP), Firefox (visual and accessibility checks).

**Spec:** `docs/specs/2026-10-08-website-design.md` (approved by the user 2026-10-08).

## Global Constraints

- Dark by default; light under `@media (prefers-color-scheme: light)`.
- Console colours: accent `#0a6ea5` (strong `#075784`, soft `#e1f0f8`); dark canvas `#0b1117`; light canvas `#f4f5f7`, text `#141b22`, secondary `#4d5965`, line `#e1e5ea` (openvibes-platform `crates/openvibes-console/web/src/styles/tokens.css`).
- No JavaScript, no web fonts, no analytics or third-party requests.
- Max content width about 1060 px; feature rows stack below 760 px; no horizontal scroll at 360 px.
- Images total under 1 MB (the site is already over Pages' 1 GB soft limit).
- **Publishing gate:** final screenshots only after the new dashboard (another session's work) is in the live demo; the PR stays a draft until then.
- Every claim true of the current release (spec §6); the verified facts are in "Content facts" below.
- Commits end with `Co-Authored-By: Claude <noreply@anthropic.com>`; the site repo's CONTRIBUTING requires AI disclosure.

```bash
#!/usr/bin/env bash
# Checks the site's pages: every local link and asset exists, every
# in-page anchor has its target, and the images stay under 1 MB (the site
# is already over GitHub Pages' size soft limit; website spec §5).
# Usage: tests/check-site.sh [DIR]   (default: the repository root)
set -euo pipefail
DIR=${1:-$(cd "$(dirname "$0")/.." && pwd)}
bad=0
fail() { echo "FAIL: $*"; bad=1; }
for page in "$DIR"/*.html; do
    name=$(basename "$page")
    while read -r ref; do
        case $ref in
            http://* | https://* | mailto:*) ;;
            '#'*) grep -q "id=\"${ref#\#}\"" "$page" || fail "$name: no id for $ref" ;;
            *) [[ -e $DIR/${ref%%#*} ]] || fail "$name: $ref does not exist" ;;
        esac
    done < <(grep -oE '(href|src)="[^"]*"' "$page" | sed -E 's/^(href|src)="(.*)"$/\2/')
done
size=0
if [[ -d $DIR/assets ]]; then
    size=$(find "$DIR/assets" -type f \( -name '*.webp' -o -name '*.png' -o -name '*.jpg' -o -name '*.svg' \) -printf '%s\n' | awk '{s += $1} END {print s + 0}')
fi
(( size <= 1048576 )) || fail "images are $size bytes, over 1 MB"
(( bad == 0 )) && echo "check-site: ok ($size bytes of images)"
exit "$bad"
```

`chmod +x tests/check-site.sh`.
