OpenVIBES packages

Signed Fedora 44 packages and the installer for OpenVIBES.

Install the platform

sudo sh -c "$(curl -fsSL https://openvibes-project.github.io/install.sh)"

It adds this repository, installs the administration tool and opens its Setup. Safer: download install.sh, read it, then run sudo sh install.sh.

Add an agent

Run the command the platform's Setup shows (or openvibes-admin agent command) on the host.

The package key

openvibes.gpg, fingerprint 710A D8AF B7AF E6E8 64C0 CDC4 E134 BAF3 7786 DA36. Check it with gpg --show-keys openvibes.gpg.
